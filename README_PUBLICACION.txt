7Dylz — Portafolio personal FINAL / preparado para GitHub Pages
============================================================

ABRIR EN TU PC
1. Descomprime el ZIP.
2. Abre index.html con Brave, Chrome o Edge.
3. Pulsa EFECTOS ON para disfrutar las animaciones y el cursor.
4. El botón MÚSICA abre un reproductor oficial de Spotify; pulsa Play dentro de Spotify.
   Si Brave bloquea Spotify, usa los enlaces externos de Spotify o YouTube.
   Para reproducir música necesitas conexión a internet.

CONTENIDO
- index.html : página completa (español inicial; cambio a inglés)
- style.css : diseño responsive, cursor, animaciones, modales y música
- script.js : comportamientos, filtros, terminal, galería y reproductor
- assets/ : imágenes WebP, avatar Killua, favicon y cursores
- .nojekyll : archivo para publicar en GitHub Pages

PUBLICAR GRATIS EN GITHUB PAGES
1. Ingresa a https://github.com y crea una cuenta si aún no tienes.
2. Crea un repositorio público llamado: TU-USUARIO.github.io
   Por ejemplo, si tu usuario de GitHub es 7dylz y está disponible: 7dylz.github.io
   Si no quieres usar ese nombre, un repositorio como '7dylz-web' también sirve.
3. Sube EL CONTENIDO de esta carpeta a la raíz del repositorio (index.html,
   style.css, script.js, assets/, .nojekyll); no la carpeta contenedora.
4. En Settings > Pages, selecciona Deploy from a branch,
   branch 'main' y carpeta '/ (root)'; guarda.
5. Espera el despliegue y abre el enlace que aparece en Pages.
   URL habitual para repo TU-USUARIO.github.io: https://TU-USUARIO.github.io/
   URL para repo 7dylz-web: https://TU-USUARIO.github.io/7dylz-web/
6. Revisa la página en móvil y verifica enlaces, música y galería.

MÚSICA Y DERECHOS
La canción 'Cuando No Era Cantante (Remix)' (El Bogueto, Anuel AA,
Fuerza Regida, Yung Beef) NO está descargada ni distribuida dentro de la web.
Se reproduce, cuando es posible, a través del reproductor incrustado oficial
ofrecido por Spotify. También hay enlaces externos a Spotify y YouTube oficial.
No hay autoplay: el visitante debe abrir el reproductor y pulsar Play.
La reproducción puede variar por navegador, geografía o cuenta.

PROYECTOS / TRANSPARENCIA
Los cuatro trabajos de la galería son IMÁGENES CONCEPTUALES GENERADAS
para la web: Neon Rain, Obsidian GT, Crimson Shrine y 7Dylz Identity.
NO son capturas de trabajos reales del usuario, modelos 3D terminados,
ediciones VFX realizadas o juegos funcionales. Están etiquetados como conceptos.
Cuando se tengan trabajos propios reales, reemplazar imágenes y descripciones.
